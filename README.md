\# Python Task Manager



\## 1. Project Description



The Python Task Manager is a command-line application developed as part of the HyperionDev Data Science Bootcamp.



The application allows users to register, log in, create and manage tasks, monitor task progress and generate reports.



This project demonstrates practical Python programming, file handling, functions, conditional statements, loops and version control.



\## 2. Features



\- User registration and login.

\- Add and assign tasks to users.

\- View all tasks.

\- View tasks assigned to the logged-in user.

\- View completed tasks.

\- Edit existing tasks.

\- Mark tasks as completed.

\- Delete tasks.

\- Display application statistics.

\- Generate task and user reports.



\## 3. Technologies Used



\- Python 3

\- Git

\- GitHub

\- Windows Command Prompt

\- Text-file data storage



\## 4. Installation Instructions



1\. Install Python 3 on your computer.

2\. Clone or download this GitHub repository.

3\. Open Command Prompt in the project directory.

4\. Create your local login file by copying the example:



```cmd

copy user.txt.example user.txt

```



5\. Open `user.txt` and replace the example password with your own password.



\*\*Important:\*\* The actual `user.txt` file is excluded from GitHub because it contains login credentials.



\## 5. Running the Application



Open Command Prompt in the project directory and execute:



```cmd

python task\_manager.py

```



Enter your username and password when prompted.



Follow the menu instructions to manage users and tasks.



\## 6. Data Storage



The application uses text files to store information:



\- `user.txt` stores login credentials locally.

\- `tasks.txt` stores task records.

\- `task\_overview.txt` stores generated task reports.

\- `user\_overview.txt` stores generated user reports.



The report files are generated by the application when the reporting functionality is used.
