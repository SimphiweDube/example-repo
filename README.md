PYTHON TASK MANAGER

PROJECT OVERVIEW

This is a command-line Task Manager application developed in Python as part of my HyperionDev Data Science Bootcamp.

The application allows users to register, log in, create tasks, assign tasks, edit task details, track completion and generate reports.

FEATURES

1. User registration and login.
2. Add and assign tasks.
3. View all tasks.
4. View tasks assigned to the logged-in user.
5. Edit task details and due dates.
6. Mark tasks as completed.
7. Delete tasks.
8. Generate reports and statistics.

TECHNOLOGIES

Python 3
File handling
Functions
Control structures

PURPOSE

This project demonstrates practical Python programming, problem-solving, user input validation and file handling.
